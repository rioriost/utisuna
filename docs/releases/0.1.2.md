# utisuna 0.1.2 (source tag only)

No binary release was published for this tag. The corrected release candidate
is 0.1.3; the original source tag is retained unchanged.

This release preparation tightens CLI input handling and makes publication explicit
and reproducible. The minimum runtime remains macOS 12; prebuilt binaries require
Apple Silicon (arm64).

- Reject role-specific requests instead of silently applying the same operation.
  `--role all` remains supported for compatibility.
- Validate sample files/package documents and application bundles before applying
  changes. Preserve valid symlinks and paths containing spaces.
- Make `--verbose` provide additional scope and consent information, and support
  `--` for literal paths beginning with a dash.
- Separate local packaging, notarization and publication. `make notarize` no
  longer publishes or notarizes twice.
- Require matching source tags and executable versions, preserve immutable
  artifacts, and preflight the Homebrew tap without committing unrelated work.
- Fix cold notarization and custom build directories. Use portable checksum
  files and a single Homebrew Formula template with explicit platform requirements.
- Expand Swift and isolated release-workflow regression coverage.
