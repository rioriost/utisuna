# utisuna 0.1.3

This release tightens CLI input handling and makes publication explicit and
reproducible. Prebuilt binaries require Apple Silicon (arm64) and macOS 12 or later.

- Reject role-specific changes instead of silently ignoring them; `--role all`
  remains supported.
- Validate sample files, package documents and application bundles. Preserve
  symlinks and paths with spaces, and support `--` before dash-prefixed paths.
- Add useful `--verbose` diagnostics.
- Separate packaging, notarization and publishing. Verify source tags, binary
  versions, immutable archives and clean Homebrew tap state before publication.
- Fix cold notarization, custom build paths, portable checksums and Formula
  generation. Declare the binary's macOS and architecture requirements.
- Add explicit `Sendable` conformances for Swift 6 toolchain compatibility.
- Cover behavior with 38 Swift tests and 43 isolated release-workflow tests.

The 0.1.2 source tag is retained unchanged; no binary release was published for it.
